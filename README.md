# Dr. Arjun Verma — Complete PHP Website

This is the full multi-page PHP build for the Dr. Arjun Verma Clinic website, using the supplied clinic logo as the canonical brand asset and the supplied prototype/reference structure as the design baseline.

## Run locally

```powershell
cd "F:\Dr.Arjun Website"
php -S localhost:8000
```

Then open:

`http://localhost:8000`

## Important

Do not double-click PHP files. PHP must be served through PHP/Apache.

## Structure

- Home
- About
- Specialities
- 14 individual speciality pages
- Locations
- Reviews
- Blogs
- 3 individual blog pages
- Clinic Gallery
- Photos
- Videos
- Contact

`assets/images/arjun-verma-clinic-logo.png` is the exact supplied logo file.
